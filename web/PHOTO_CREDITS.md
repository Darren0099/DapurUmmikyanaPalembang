# Sumber foto ilustrasi — frontend Dapur Ummi Kyana

**PENTING:** foto berikut menampilkan masakan **ilustratif dari fotografer pihak ketiga**, bukan dokumentasi hidangan yang dijual Dapur Ummi Kyana. Label *Foto ilustrasi* ditampilkan pada website. Foto produk milik merchant yang diisi melalui admin / `products.image_url` selalu memiliki prioritas tertinggi.

Semua foto diambil dari halaman yang ditandai gratis digunakan berdasarkan [Lisensi Unsplash](https://unsplash.com/license). Jangan gunakan gambar dari preview proyek web referensi maupun Getty Images.

Tampilan foto tidak boleh dipakai sebagai dasar menentukan porsi, kualitas, isi paket, atau harga asli produk. Ganti melalui kolom `image_url` menggunakan foto pemilik usaha, setelah database Supabase aktif.
